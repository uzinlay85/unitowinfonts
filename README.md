# Win Researcher ⇄ Pyidaungsu (Myanmar Font Converter)

> **Win Researcher (TrueType - Legacy)** နှင့် **Pyidaungsu (OpenType - Myanmar Unicode)** ဖောင့်နှစ်ခုကို အပြန်အလှန် (Bidirectional) အမှားအယွင်းမရှိ ပြောင်းလဲပေးနိုင်သော မြန်မာဖောင့်စနစ် ဖြစ်ပါသည်။

ဤစနစ်သည် မြန်မာစာလုံးများအကြား ပါဝင်လာသော **English စာလုံးများ (အမည်များ၊ ဝေါဟာရများ၊ အတိုကောက်များ၊ Email၊ Website လိပ်စာ၊ ဖုန်းနံပါတ်၊ ရက်စွဲများ)** ကို ပျက်စီးမသွားစေဘဲ သီးသန့် အလိုအလျောက် ခွဲခြားထိန်းသိမ်းပေးပါသည်။ ထို့အပြင် **အခြေခံဗျည်းတွဲ ၄ မျိုး (ယပင့်၊ ရရစ်၊ ဝဆွဲ၊ ဟထိုး)**၊ ၎င်းတို့၏ **ပေါင်းစပ်ဗျည်းတွဲများ**၊ **အသတ်စနစ်များ**၊ **ပါဠိဆင့်များ** နှင့် **Microsoft Word (.docx)** ဖိုင်များကိုပါ မူရင်းအတိုင်း တိကျစွာ ပြောင်းလဲပေးနိုင်ပါသည်။

   * **စကားလုံး ၂၀,၀၀၀ ကျော်ပါ အဘိဓာန်:** အင်္ဂလိပ်စာလုံးများကို အလိုအလျောက် ရှာဖွေထိန်းသိမ်းပေးသဖြင့် မြန်မာစာလုံးများနှင့် ရောနှောမသွားပါ။

3. **မြန်မာစာသဒ္ဒါစနစ်နှင့် ဗျည်းတွဲ/အသတ်စုံ စနစ်တကျ ပြင်ဆင်ထားမှု**
   * **ကော်မာ ပြဿနာ ဖြေရှင်းထားမှု:** မြန်မာစာသားထဲတွင် ကီးဘုတ်မှ English Comma (`,`) ရိုက်ထည့်ထားပါက Win Researcher တွင် "ယ" အဖြစ် မှားယွင်းမပေါ်စေဘဲ မှန်ကန်သော မြန်မာပုဒ်ဖြတ် (၊ - ကုတ်သင်္ကေတ `?`) အဖြစ် အလိုအလျောက် ပြောင်းလဲပေးပါသည်။
   * **လျှပ် (`vQyf`):** ယပင့်-ဟထိုး Ligature `Q` ကို စနစ်တကျ သုံးထားသဖြင့် `လ ျှပ်` မဖြစ်တော့ဘဲ ပုံစံအမှန် `လျှပ်` ထွက်ရှိပါသည်။
   * **မြို့ (`NrdKU`):** အပေါ်ဖွင့်ရရစ် `N` နှင့် `ိ` + `ု` + `့` တွဲစပ်မှု မှန်ကန်သဖြင့် `သိကြား-မို့` မဖြစ်ဘဲ `သိကြားမြို့` အဖြစ် အတိအကျ ပေါ်ထွက်ပါသည်။
   * **ပါဠိဆင့်နှင့် အထူးအက္ခရာများ:** `ဝဍ္ဎန` (`0¹e`), `သီဟိုဠ်` (`oD[dkVf`), `ဉာဏ်` (`ÓPf`), `ညွှန်း` (`ñTef;`), `ချွတ်` (`cRwf`), `အံ့ဩ` (`tHhMo`), `၏/၌/၍/၎/၎င်း` အားလုံး ၁၀၀% မှန်ကန်စွာ ပြောင်းလဲနိုင်ပါသည်။

4. **Microsoft Word (.docx) နှင့် Text (.txt) ဖိုင်များ တိုက်ရိုက်ပြောင်းနိုင်ခြင်း**
   * Word (.docx) ဖိုင်များကို Drag & Drop ဆွဲထည့်ရုံဖြင့် စာရွက်စာတမ်းတစ်ခုလုံးရှိ ဇယားများ (Tables)၊ Bold၊ Italic၊ အရွယ်အစား စသည့် ပုံစံများကို မပျက်စီးစေဘဲ ဖောင့်ပြောင်းပေးပါသည်။
   * Pyidaungsu မှ Win Researcher သို့ ပြောင်းရာတွင်လည်း Word ထဲတွင် မြန်မာစာကို `Win Researcher` ဖောင့်ဖြင့် လည်းကောင်း၊ English စာကို `Times New Roman` ဖောင့်ဖြင့် လည်းကောင်း သီးခြားစီ အလိုအလျောက် Format သတ်မှတ်ပေးပါသည်။

5. **Real Font Visual Preview (ဖောင့်အစစ်ဖြင့် အစမ်းမြင်ကွင်း)**

## 🚀 အသုံးပြုနည်း အပြည့်အစုံ လမ်းညွှန်ချက် (User Guide)

### နည်းလမ်း (၁) - Browser ဖြင့် တိုက်ရိုက် အသုံးပြုခြင်း (အလွယ်ကူဆုံး)
မည်သည့် Server မှ Run ရန်မလိုဘဲ အင်တာနက်မရှိလည်း တိုက်ရိုက် သုံးနိုင်ပါသည်-
1. ဖိုဒါထဲရှိ `index.html` ဖိုင်ကို Double-Click နှိပ်၍ Chrome / Edge / Firefox တွင် ဖွင့်ပါ။
2. **မူရင်းစာသား (Input)** အကွက်ထဲတွင် မိမိပြောင်းလိုသော စာသားကို ရိုက်ထည့်ပါ (သို့မဟုတ်) `Ctrl + V` ဖြင့် ကူးထည့်ပါ။
3. ချက်ချင်း **ပြောင်းလဲပြီး စာသား (Output)** အကွက်နှင့် **ဖောင့်အစစ် အစမ်းမြင်ကွင်း (Real Font Preview)** တွင် ရလဒ် ပေါ်လာပါမည်။
4. အထက်ရှိ **`⇄` (Swap)** ခလုတ်ကို နှိပ်၍ Win Researcher မှ Pyidaungsu သို့ လည်းကောင်း၊ Pyidaungsu မှ Win Researcher သို့ လည်းကောင်း ဦးတည်ရာကို ပြောင်းနိုင်ပါသည်။
5. **📋 Copy** ခလုတ်ဖြင့် စာသားကူးယူနိုင်ပြီး၊ **📄 Word ပုံစံ Copy** ကို နှိပ်ပါက MS Word ထဲတွင် အင်္ဂလိပ်စာနှင့် မြန်မာစာ ဖောင့်မပျက်ဘဲ ကပ်နိုင်စေရန် ကူးယူပေးပါသည်။

### နည်းလမ်း (၂) - Launcher ဖြင့် Web Server ဖွင့်လှစ်ခြင်း (Word .docx ပြောင်းရန်)
Microsoft Word ဖိုင်များကို တစ်ဖိုင်လုံး စနစ်တကျ ပြောင်းလဲလိုပါက-
1. ဖိုဒါထဲရှိ `Start_Converter.bat` ဖိုင်ကို Double-Click နှိပ်ပါ။
2. Browser တွင် `http://localhost:5000` အလိုအလျောက် ပွင့်လာပါမည်။
3. အောက်ခြေရှိ **ဖိုင်တင်သွင်းသည့်နေရာ (File Drop Zone)** ထဲသို့ မိမိ၏ Word (`.docx`) သို့မဟုတ် Text (`.txt`) ဖိုင်ကို ဆွဲထည့်ပါ (Drag & Drop) သို့မဟုတ် နှိပ်၍ ရွေးချယ်ပါ။
4. စနစ်က ဖောင့်ပြောင်းလဲပြီးပါက ပြောင်းလဲပြီးဖြစ်သော Word ဖိုင်အသစ်ကို Auto Download ပြုလုပ်ပေးပါမည်။

### နည်းလမ်း (၃) - Command Line Interface (CLI) ဖြင့် အသုံးပြုခြင်း

```bash

# ၂။ Pyidaungsu မှ Win Researcher သို့ ပြောင်းရန် (.docx)
python converter_cli.py input.docx output.docx --direction uni2win

# ၃။ Text (.txt) ဖိုင်များ ပြောင်းရန်
python converter_cli.py input.txt output.txt --direction win2uni
python converter_cli.py input.txt output.txt --direction uni2win
```
